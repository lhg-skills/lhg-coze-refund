# lhg-coze-refund · 扣子会员退款助手

**Coze Membership Refund SOP** — 帮用户退掉扣子（Coze 国内版）的付费会员、拿回剩余价值。精确到每次点击的路径：登录态检查 → 订阅管理页查会员状态 → 决策树（留用到期 / 申请退款）→ 支付记录点「申请退款」→ 用户确认后提交 → 四项核验。全流程 2026-10-12 实测走通（个人高阶版连续包年，申请 ¥869 实到 ¥867.10）。

## 为什么你之前找不到退款入口

1. **藏得深**：入口不在会员中心首页，而在 订阅管理 → 套餐管理 → 支付记录 → 订单行操作列，四层嵌套。
2. **叫法错位**：你找的是「退订/取消会员」，页面上叫「申请退款」——关键词对不上就等于隐身。
3. **自动续费已关时没有"取消"按钮**：到期自动失效，没什么可取消的，唯一出路就是退款。
4. **手机端可能根本没有**：本次在桌面网页端走通，扣子 App 内导航结构不同。

## 人机分工

- **Agent 做**：开页面、查状态、找入口、走到确认弹窗前、四项核验。
- **用户做**：扫码登录（或亲口给短信验证码）、明确说"确认退款"、2-3 个工作日后查原支付卡到账。
- **Agent 绝不**：替用户输密码、读用户短信、猜手机号。

## 关键决策点

自动续费已关闭的账号到期后不会再扣费，所以先有决策再动手：

- **A. 什么都不做**：权益保留到到期日，零操作零风险。
- **B. 申请退款**：拿回剩余价值，但**立即收回全部剩余权益，不可撤销**。
